## TRACERT-AS
10 баллов

Написать скрипт, который выводит маршрут (traceroute) и номера автономных систем
промежуточных узлов, используя ответы службы whois региональных регистраторов.

Вход:
IP-адрес или DNS-имя (передаётся в качестве аргумента командной строки)

Выход:
1. Вывести результат трассировки в пределах разумного TTL, для «белых» IP-адресов указать
номер автономной системы и название сети.
2. Обращаться к правильному whois-серверу и определять страну промежуточного IP-адреса.
3. Самостоятельно реализовать traceroute (сборка пакета с нужным TTL и разбор ICMP).

### Запуск
```
python tracert.py yandex.com
```

## SNTP
7 баллов
Написать «обманывающий» сервер времени.

Вход:
Смещение относительно точного времени в секундах (положительное или отрицательное).
./sntp.py -d 5

Выход:
Порт, который слушаем (по умолчанию 123).
Сервер в ответе добавляет 5 секунд к текущему времени.
Сервер сообщает на STDOUT о начале работы, при подключении клиента выводит его IP-адрес.

### Запуск в разных окнах
```
python sntp.py
```

## Port Scan

15 баллов
Сканер пытается установить соединение с каждым портом в заданном диапазоне.
Если соединение успешно - порт считается открытым.

### Запуск
```
python portscan.py --tcp --start 1 --count 1000 127.0.0.1
python portscan.py --tcp --start 1 --count 100 chess.com
python portscan.py --tcp --start 53 --count 1 8.8.8.8
```

## DNS cache

20 баллов
Написать DNS сервер:
1. Кэш на основе query records: cache_key = (domain, qtype)  # Ключ = (имя, тип)
2. Парсинг пакета для кэша(имени и извелечение из ответа от форвардера)
3. Самостоятельная сборка пакета
4. Корректный TTL и отказоустойчивость
5. Логирование
6. Разбор аргуметов командной строки

### Запуск в разных окнах
```
python dnsc.py -p 53 -f 8.8.8.8
```
```

nslookup -type=MX urfu.ru 127.0.0.1
```

## IMAP

10 баллов
Скрипт должен подключаться к серверу, выбирать диапазон писем и выводить:
1. Заголовки (From, To, Subject, Date, размер)
2. Декодированные заголовки (чтобы читалась кириллица)
3. Работу по SSL/TLS по флагу --ssl
4. Информацию о вложениях (имена, размеры)

### Запуск (почта, далее ввод пароля приложения)
```
python3 imap.py -s imap.mail.ru -u example@com
python3 imap.py --ssl -s imap.mail.ru -u example@com -n 1 3
```
